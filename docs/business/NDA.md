Version: 1.0

## Purpose

Confidential information may be shared for work such as:

- Development
- Testing
- Security review
- Design
- Payment integration
- Business evaluation
- Partnership discussion
- Marketing work
- Infrastructure work

## What is confidential

Confidential information may include:

- Source code
- Database schema
- Supabase configuration
- Security design
- RLS policies
- Secure RPCs
- Edge Functions
- Admin workflows
- Product roadmap
- Business plans
- Customer information
- Credentials
- API keys
- Internal documentation
- Non-public financial information

## What is not confidential

Information is not confidential if the receiving party can show that it:

- Was already lawfully known
- Became public without violating this agreement
- Was received lawfully from another source
- Was developed independently without using the confidential information

## Responsibilities of the receiving party

The receiving party agrees to:

- Use the information only for the agreed purpose
- Protect it with reasonable care
- Share it only with authorized people who need it
- Avoid unauthorized disclosure
- Avoid misuse of privileged access
- Report known unauthorized disclosure

## Source code and security information

ExCloth source code, backend logic, admin authorization, RLS policies, Edge Functions, secrets, and security documentation should be treated as confidential unless explicitly made public.

## Credentials

The receiving party must not:

- Share production credentials
- Put secrets in a public repository
- Put service-role keys inside client code
- Keep credentials after access is no longer required

## Legally required disclosure

If disclosure is legally required, the receiving party should disclose only what is required and should notify the disclosing party where the law allows it.

## Return or destruction

When the relationship ends, confidential information should be returned or securely destroyed unless there is a valid legal reason to retain it.

## Ownership

Sharing confidential information does not transfer ownership or intellectual-property rights.
